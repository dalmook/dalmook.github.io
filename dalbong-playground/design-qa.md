## 수정 후 확인

P1: 초기 모바일 레이아웃 넘침을 수정하고 390×844, 320×568에서 홈 주요 조작과 하단 메뉴가 화면 안에 보이는 것을 확인했다. 1366×768 데스크톱도 문서 스크롤이 없다.

P2: 쇼츠 배경의 음수 inset으로 포커스 시 장면 상단이 잘리는 현상을 수정했다. 그림과 자막을 분리해 행동이 자막에 가려지지 않는다. 문장 줄바꿈과 긴 자막을 조정했다. 추천 패널의 글씨와 간격을 시안과 다시 비교해 확대했다.

글꼴은 Noto Sans KR와 시스템 대체 글꼴, 제목의 굵기와 본문 계층을 확인했다. 네이비·아이보리·오렌지 색 체계, 카드와 패널의 간격, 생성 이미지 실제 로딩, 한글 문구 및 CTA를 검토했다. 초기 화면에는 구현되지 않은 계정·알림 버튼을 넣지 않았다. 시안의 장식용 도시 실루엣과 손글씨는 제외했고 실제 필터 값과 게임 데이터를 사용했다. 픽셀 단위 복제를 주장하지 않는다.

## 동작 검수

자동 테스트 7개 통과, 정적 빌드 성공. 62개 도감 항목을 모바일 16페이지에서 중복·누락 없이 확인했다. 조건 필터, 후보가 없는 상태, 룰렛·주사위 2개·사다리·카드 결과, 즐겨찾기와 최근 기록의 새로고침 유지, 안전 확인 후 놀이 타이머, 수집 기록을 실제 브라우저로 확인했다. 쇼츠 자동 종료, 다시보기, 일시정지, 장면 이동이 동작한다. 브라우저 오류·경고 로그는 비어 있었다.

62개 생성 스토리보드를 검토하고 무궁화 동결 동작, 딱지 뒤집기, 윷 네 개, 초성 예시, 실뜨기 모양을 수정했다. 이미지 쇼츠는 생성 일러스트 4컷에 장면 전환과 웹 모션을 적용한 형식이며 실제 촬영 영상이나 I2V 동영상이 아니다. 세부 규칙은 지역별로 달라질 수 있다.
