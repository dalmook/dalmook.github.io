P2: 쇼츠 배경의 음수 inset으로 포커스 시 장면 상단이 잘리는 현상을 수정했다. 그림과 자막을 분리해 행동이 자막에 가려지지 않는다. 문장 줄바꿈과 긴 자막을 조정했다. 추천 패널의 글씨와 간격을 시안과 다시 비교해 확대했다.

## 동작 검수

자동 테스트 7개 통과, 정적 빌드 성공. 62개 도감 항목을 모바일 16페이지에서 중복·누락 없이 확인했다. 조건 필터, 후보가 없는 상태, 룰렛·주사위 2개·사다리·카드 결과, 즐겨찾기와 최근 기록의 새로고침 유지, 안전 확인 후 놀이 타이머, 수집 기록을 실제 브라우저로 확인했다. 쇼츠 자동 종료, 다시보기, 일시정지, 장면 이동이 동작한다. 브라우저 오류·경고 로그는 비어 있었다.

62개 생성 스토리보드를 검토하고 무궁화 동결 동작, 딱지 뒤집기, 윷 네 개, 초성 예시, 실뜨기 모양을 수정했다. 이미지 쇼츠는 생성 일러스트 4컷에 장면 전환과 웹 모션을 적용한 형식이며 실제 촬영 영상이나 I2V 동영상이 아니다. 세부 규칙은 지역별로 달라질 수 있다.

미해결 P0/P1/P2 발견 사항 없음. 확대·작은 화면에서는 접근성을 위해 필요한 패널 내부 스크롤을 허용한다. 아동·교사 대상 사용성 실험은 수행하지 않았다.

## 2026-09-30 글자 잘림 재검수

사용자 제보 화면에서 다방구 3장면의 마지막 줄이 잘렸다. 이전 검수는 대표 장면을 주로 확인했고, 자막 영역이 좁을 때 제목을 내부 스크롤로 감추는 문제를 놓쳤다. 이 판정을 폐기하고 전체 장면으로 검수 범위를 넓혔다.

- 쇼츠 그림은 원래 2:3 비율을 유지한다. 모바일에서는 자막을 그림 폭에 묶지 않고 플레이어 전체 폭으로 표시한다. 자막 높이는 내용에 따라 늘어나며 숨김/스크롤로 문장을 자르지 않는다.
- 62개 놀이 × 4장면 × 4개 화면 크기(320×568, 390×844, 768×1024, 1366×768) = **992개 장면 상태**를 실제 브라우저에서 확인했다. 각 장면의 제목 scrollHeight/clientHeight, 제목과 자막 상자 및 플레이어의 경계, 문서 가로·세로 넘침을 측정했다. 실패 0건.
- 홈·도감·룰렛·주사위·사다리·카드·보물함·상세 화면을 같은 네 크기에서 점검했다. 홈의 좁은 조건 선택 칸은 기본 표기를 ‘전체’로 줄였다. 작은 룰렛·카드 화면은 후보 영역 내부에서만 스크롤한다.
- [고친 다방구 3장면 실제 캡처](research/v2/caption-fix-mobile.webp), 390×844.

자동 경계 측정은 시각적 선호도를 판정하지 않는다. 제보 장면과 작은 화면의 다른 주요 화면은 캡처를 직접 확인했다.
