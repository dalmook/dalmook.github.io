# v2 변경 내역

- `index.html`, `css/cinema.css`: 긴 세로 페이지를 화면 높이에 맞는 앱으로 교체. 네이비 탐색·아이보리 화면·주황 CTA, 모바일 하단 4탭.
- `js/cinema-app.js`: 페이지형 도감, 검색/8가지 조건, 비슷한 놀이, 상세 탭, 타이머, 보물함 통합.
- `js/cinema-player.js`: 실제 생성된 놀이별 4컷 이미지 쇼츠, 그림과 자막 분리, 자동 재생/일시정지/다시보기/장면 이동/기기 음성.
- `js/pickers.js`: 새 이미지 카드와 Lucide 주사위, 두 주사위 후보 셔플 개선. 기존 사다리 경로와 돌림판 선택 로직 유지.
- `data/games.json`: 62개 놀이의 생성 이미지 경로와 2×2 스토리보드 메타데이터 연결.
- `assets/images/v2/*.webp`: 달봉이 히어로 + 놀이별 62장 스토리보드(각 4장면).
- `assets/icons/ui/`: 로컬 아이콘과 라이선스.
- `scripts/build.mjs`: 실제 사용 파일만 dist로 복사. 원본 대형 PNG 제외.
- `scripts/publish-manifest.mjs`: UTF-8 코드와 base64 바이너리 자산을 구분하는 게시 목록.
- `README.md`, `research/v2/RESEARCH.md`, `design-qa.md`: 사용/데이터/배포 안내와 근거·검수 기록.

쇼츠는 이미지 기반 웹 플레이어이며 연속 동작 I2V 영상은 아닙니다. 소리 안내는 사용자가 켠 경우에만 기기 음성 기능을 사용합니다. 모든 방문자에게 동일한 음질/음성이 제공되는 녹음 파일은 아닙니다.

검수 결과와 실제 캡처는 `design-qa.md`를 참조하세요. 루트 저장소에는 기존 다른 HTML 파일의 검사 실패가 있을 수 있으며 앱 전용 테스트와 구분합니다.
