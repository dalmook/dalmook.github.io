# 달봉이의 놀이동산 · 골목놀이 시네마

[바로 사용하기](https://dalmook.github.io/dalbong-playground/)

오늘 뭐 하고 놀지? 62가지 골목·전통·실내 놀이를 고르고, 달봉이와 친구들의 4컷 이미지 쇼츠로 준비부터 안전 약속까지 배웁니다. 로그인, 결제, 서버 API 없이 동작하는 HTML/CSS/ES module/JSON 정적 웹앱입니다.

## v2에서 달라진 점

- 긴 랜딩 페이지를 없애고 화면 높이에 맞는 4탭 앱으로 전면 개편했습니다. 홈에서 장소·인원·시간을 선택하고 바로 추천받습니다.
- 모바일 도감은 한 번에 4개, 데스크톱은 6개의 놀이를 보여주며 이전/다음으로 이동합니다.
- 새 달봉이 캐릭터와 놀이별 4개 장면을 AI 이미지 생성으로 제작했습니다. 사진처럼 입체적인 그림을 실제 로컬 WebP 자산으로 제공합니다.
- 쇼츠는 준비 → 실제 행동 → 결과/차례 → 안전의 24~30초 시퀀스입니다. 그림에 자막이 겹쳐 도구를 가리지 않도록 설명 영역을 분리했습니다.
- 화면 아래의 재생·이전/다음·다시보기 버튼을 유지합니다. 규칙·준비물은 같은 화면의 탭에서 확인합니다.
- 돌림판, 1·2개 주사위, 사다리, 카드 뽑기와 즐겨찾기·최근 본 놀이·해본 놀이·배지를 제공합니다.

**표현 범위:** 이 앱은 AI 일러스트와 웹 장면 전환을 조합한 **이미지 쇼츠**입니다. 캐릭터가 연속 동작하는 실제 촬영 영상이나 생성형 I2V 동영상은 아닙니다. 소리를 켜면 기기의 한국어 음성 합성을 사용할 수 있습니다. 목소리와 지원 여부는 브라우저/운영체제에 따라 달라집니다.

## 실행

Node.js 20 이상:

```sh
npm start
```

`http://127.0.0.1:4173/`에서 확인합니다. 별도 의존성 설치는 필요 없습니다. `file://`로 직접 열면 JSON 로딩이 제한될 수 있으므로 HTTP 서버를 사용합니다.

```sh
npm test
npm run build
```

정적 배포 결과는 `dist/`입니다. 글꼴은 Google Fonts의 Noto Sans KR을 사용하며 연결이 없으면 시스템 글꼴로 표시합니다. 이미지·아이콘·게임 데이터는 프로젝트 안에 있습니다. 계정 정보나 분석 추적 코드는 없습니다. 보물함과 저장 조건은 해당 브라우저의 localStorage에 남습니다. 사이트 데이터를 지우면 초기화됩니다.

## 사용 방법

1. **오늘의 놀이:** 장소·실제 인원·시간 선택 → 추천. 추가 조건에서 활동량·소음·나이·준비물·팀전·위험도를 선택하고 저장할 수 있습니다.
2. **놀이 도감:** 검색, 카테고리, 처음 보는 놀이, 페이지 이동. 정확히 맞는 결과가 없으면 변경이 필요한 조건을 표시합니다. 뽑기에는 정확히 맞는 후보만 들어갑니다.
3. **행운의 뽑기:** 4가지 방식 중 선택 → 결과 → 쇼츠로 배우기. 다시 뽑을 수 있습니다. 두 주사위의 첫 눈은 행, 둘째 눈은 열입니다.
4. **놀이 설명:** 자동 재생, 장면 선택, 일시정지, 다시보기. 규칙/안전/비슷한 놀이 확인 후 공간을 점검하고 타이머를 시작합니다.
5. **내 보물함:** 하트로 저장한 놀이, 최근 본 놀이, 완료한 놀이를 확인합니다.

모바일 390×844, 데스크톱 1366×768을 기준으로 문서 스크롤 없이 핵심 동작을 수행하도록 설계했습니다. 작은 화면, 가로 화면, 글자 확대에서는 필요한 패널 내부 스크롤을 허용합니다. 키보드 Tab, Enter를 지원하며 쇼츠 영역에서는 좌우 화살표로 장면을 이동합니다. 동작 줄이기 설정을 존중합니다.

## 놀이 추가 / 수정

`data/games.json`의 기존 항목을 복사하고 고유한 `id`를 지정합니다. 제목, 소개, 장소, 최소/최대 인원, 연령, 활동량, 소음, 시간, 난이도, 준비물, 안전, 규칙, 팁, 태그를 수정합니다. `minPlayers`/`maxPlayers`/`minAge`/`durationMin`은 숫자입니다. `materials`가 빈 배열이면 준비물 없음으로 분류합니다.

이미지는 같은 캐릭터를 유지하면서 준비/행동/결과/안전을 각각 그립니다. 현재 플레이어는 2×2 그리드의 4장면을 사용합니다. 전체 권장 크기 1024×1536, 장면 한 칸은 512×768입니다. `assets/images/v2/새-id.webp`에 저장하고 다음 경로를 연결합니다.

```json
{
  "thumbnail": "assets/images/v2/새-id.webp",
  "illustration": "assets/images/v2/새-id.webp",
  "storyboard": {
    "image": "assets/images/v2/새-id.webp",
    "columns": 2,
    "rows": 2,
    "panelAspectRatio": "2:3",
    "artType": "AI-generated illustration"
  }
}
```

`shortScenes`는 정확히 4개입니다. 각 장면에 `sceneTitle`, `caption`, `narration`, `characterAction`, `backgroundType`, `duration`, `panel`을 입력합니다. 순서는 왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래이며 총 15~30초를 권장합니다. 실제 규칙과 그림 속 도구 개수·방향·차례가 맞는지 반드시 검수합니다. 지역별 놀이 차이가 있어 앱은 ‘달봉이 쉬운 규칙’임을 표시합니다.

`scripts/create-data.mjs`는 v1 초기 시드 도구이므로 운영 데이터를 편집한 뒤 다시 실행하지 마세요. 기존 항목을 직접 편집하는 방식이 기본입니다. 이미지 생성은 빌드에 포함되지 않으며 유지보수 시 별도로 제작합니다.

## GitHub Pages

현재는 `dalmook/dalmook.github.io`의 `dalbong-playground/` 하위 폴더로 서비스합니다. 상대 경로와 해시 라우터를 사용하므로 새로고침에 서버 rewrite가 필요 없습니다.

**현재 저장소:** 검수한 파일을 하위 폴더에 커밋하고 main에 반영하면 기존 Pages 게시가 수행됩니다. 루트 사이트의 다른 파일은 변경하지 않습니다.

**별도 저장소:** 앱 파일을 저장소 루트에 넣고 Settings → Pages → Deploy from a branch → main / root를 선택합니다. 또는 `npm run build` 후 `dist/`를 Pages artifact로 배포하는 Actions를 사용합니다. 원본 PNG, 로컬 검수 결과, node_modules는 배포에 필요 없습니다.

배포 후 홈, JSON, WebP가 HTTP 200으로 열리는지 확인하고 모바일에서 추천 → 선택 → 설명 → 보물함 흐름을 직접 확인합니다. 배포 성공은 시각 검수의 대체가 아닙니다.

## 자산과 조사

달봉이와 놀이 장면은 이 프로젝트를 위해 AI로 새로 생성했습니다. 경쟁 서비스의 그림이나 박물관 일러스트를 복제하지 않았습니다. Lucide 아이콘의 ISC/MIT 관련 고지는 `assets/icons/ui/LICENSE`에 보존합니다. 조사 출처와 관찰 범위는 [조사 문서](research/v2/RESEARCH.md)에 기록했습니다. 어린이 대상 현장 사용성 시험을 수행한 것은 아닙니다.
