# 달봉이의 놀이동산 전면 개편 조사 · 2026-09-28

## 사용자에게서 확인된 문제

기존 공개 버전을 실제로 방문하고 홈 → 딱지치기 상세 → 쇼츠 흐름을 캡처했다. 사진은 같은 폴더의 `01-before-home.png`, `02-before-shorts.png`에 보관했다.

1. 홈: 712px 높이 화면에서 조건 선택조차 아래로 밀린다. 실제 작업보다 큰 소개 영역이 우선한다. 긴 페이지가 사용자 요구와 충돌한다.
2. 상세: 장문의 규칙과 카드가 반복되고 쇼츠 시작까지 별도 화면을 거친다. 주요 CTA가 하나로 명확하지 않다.
3. 쇼츠: 두 캐릭터와 배경이 반복되고 딱지의 실제 손동작·뒤집힘·차례가 구분되지 않는다. 그림을 흔드는 것과 규칙 설명은 다르다. 플레이어 하단도 화면 밖으로 내려간다.
4. 접근성: 작은 부가 글씨, 흐린 색, 화면 아래의 제어 버튼 때문에 읽기와 발견 비용이 높다. 스크린샷만으로 접근성 준수 전체를 판단하지는 않는다.

## 개편 설계: 골목놀이 시네마

- 홈: 화면 높이에 맞춰지는 앱 셸. 주요 추천 장면 + 조건 3개 + 시작. 긴 소개/푸터/반복 카드 섹션 제거.
- 모바일: 상단 브랜드, 메인 장면, 추천 버튼, 고정 하단 4탭. 불필요한 스크롤 없이 핵심 동작 수행.
- 도감: 화면에 맞는 제한된 카드 수와 이전/다음 버튼. 62개를 한 번에 아래로 쌓지 않음.
- 상세/쇼츠: 사진 기반 4컷 설명을 우선 표시. 준비·규칙·결과·안전을 구분하고 재생 제어를 항상 보이게 배치. 규칙 전문은 탭으로 이동.
- 조건: 기본 장소·실제 인원·시간만 먼저. 나머지는 별도 조건 패널.
- 아트: 새로 생성한 달 모양 이마 표식의 노란 곰 달봉이, 청록 멜빵/아이보리 티/주황 가방. 한국 골목과 교실의 입체 애니메이션 질감. 생성 이미지와 웹 장면전환을 사용하며 실제 I2V 동영상이라고 부르지 않음.
- 촬영 설계: 게임별 준비 전경 → 행동 중경 → 결과 클로즈업/다른 각도 → 안전 장면. 같은 그림 4개 반복 금지.
- 도구: 4가지 선택 미니게임 유지. 조건을 만족한 후보만 사용. 결과 확인 후 바로 설명으로 이동.

## 완료 판정 기준

- 기본 글씨 14px 이상, 주요 조작 44px 이상을 목표로 한다.
- 390×844 및 1366×768에서 홈·도감·선택·설명 화면의 문서 스크롤이 없어야 한다. 작은 화면/확대 시 접근성을 위해 패널 내부 스크롤은 허용한다.
- 썸네일이 놀이를 구분하고, 쇼츠의 장면마다 다른 행동·정보를 설명해야 한다.
- 생성 이미지가 실제 런타임에서 로딩되어야 한다. 예전 SVG를 새 이미지처럼 설명하지 않는다.
- 선택 결과·필터·즐겨찾기·재생·모바일 크기를 실제 브라우저로 확인한다.

## 다음번 요청에 쓸 수 있는 짧은 품질 기준

“마케팅 랜딩 페이지가 아닌 한 화면 앱으로 만들어라. 먼저 유사 서비스의 실제 화면과 이용 흐름을 조사하고 근거를 남겨라. 캐릭터와 놀이별 행동 장면을 이미지 생성으로 제작하라. 설명은 준비·동작·결과가 시각적으로 달라야 하며 반복 SVG나 줌만으로 완료라 하지 마라. 실제 화면에서 검수한 뒤 기존 공개 사이트를 교체하라.”

이번 요청은 이미 충분히 구체적이었다. 위 문구는 구현자가 지켜야 할 검수 기준을 짧게 정리한 것이며 사용자에게 책임을 돌리는 의미가 아니다.

## 국내 자료 추가 확인
[국립민속박물관 어린이박물관 우리 놀이 알기](https://nfm.go.kr/kids/nfmkid/material/materialKnowingPlay.do)의 놀이별 일러스트 목록과 별도 집콕 민속놀이 진입을 확인했다. 전통놀이를 그림으로 구별하고 실내 대안을 별도로 찾게 하는 방식은 참고했다. 해당 이미지의 외부 복제·배포·2차 활용 제한을 확인하여 자산은 가져오지 않았고 프로젝트용 그림을 새로 생성했다. 이 페이지를 확인했다는 사실은 62개 게임 규칙 전체의 학술 검증을 뜻하지 않는다.
