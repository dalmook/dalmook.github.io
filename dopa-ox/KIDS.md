# 키즈: 초등학교 1학년 입문 문제

키즈는 어린이가 짧은 문장을 읽고 직접 아는 것을 떠올려 답하는 단계입니다. 어려운 사실을 암기하는 시험이 아닙니다. 전체 200문항은 생활·상식·한글 110문항과 기초 수학 90문항입니다. 학년 전체 교육과정과 동일하다는 뜻은 아니며, 처음 시작하는 어린이에게 맞추어 의도적으로 범위를 좁혔습니다.

수학 범위 선정 시 EBS의 초등 1-1 강의와 충북자연과학교육원의 1학년 수 세기·비교하기·덧셈과 뺄셈 안내를 참고했습니다. 교재 문항을 복제하지 않았습니다.

- EBS 2022 개정 만점왕 수학 1-1: https://primary.ebs.co.kr/educerti/learning/courseView?courseId=100004633
- 충북자연과학교육원 1학년 수 세기: https://www.cbnse.go.kr/math/sub.php?menukey=19&mod=view&no=12618

## 생활 관찰

이 링크가 붙은 문항은 논문·기관 자료에서 조사한 전문 상식이 아니라, 쉬운 현상을 직접 확인하도록 만든 문항입니다. 손뼉의 소리, 물과 얼음, 잎의 흔들림, 붓과 색연필, 찰흙 등 눈앞의 물건과 일상 현상을 기준으로 답과 해설을 작성했습니다. 어른이 일상적인 사용 모습을 보여 주고 아이가 확인할 수 있습니다. 전기제품을 열거나 뜨거운 물·불·약품을 사용하는 실험은 포함하지 않습니다.

나무는 살아 있는 식물이고, 돌은 잎을 기르는 식물이 아닙니다. 씨앗은 조건이 맞으면 싹을 틔웁니다. 소리는 귀로 듣고, 눈으로는 물건을 봅니다. 얼음은 차갑고 녹으면 물이 됩니다. 풍선은 들어간 공기 때문에 부풀고, 전등은 빛을 내어 주변을 밝힙니다. 이 확인 안내는 독립된 외부 검증 기관을 사칭하지 않습니다.

## 낱말 뜻

이 링크의 문항은 아래 낱말의 기본 뜻을 확인합니다. 난도 높은 고유명사와 연도는 묻지 않습니다.

| 낱말 | 이 게임에서 사용하는 뜻 |
|---|---|
| 섬·산·지도·다리·사막 | 물에 둘러싸인 땅 / 높이 솟은 땅 / 길과 장소를 나타낸 그림 / 건너편으로 이어 주는 시설 / 비가 적게 오는 땅 |
| 박물관·한옥·기와·궁궐 | 옛 물건 등을 보관하고 보여 주는 곳 / 우리 전통 집 / 지붕을 덮는 재료 / 왕실이 지내던 곳 |
| 한복·설날·송편·윷놀이·세배·김치 | 전통 옷 / 새해 명절 / 추석에 먹는 떡 / 윷가락과 말을 쓰는 놀이 / 새해에 드리는 절과 인사 / 채소로 만드는 음식 |
| 동화·피아노·북·색연필 | 어린이를 위한 이야기 / 건반 악기 / 두드리는 악기 / 색을 그리는 도구 |
| 수영·달리기·줄넘기·숨바꼭질·농구·스케이트 | 물속에서 헤엄치기 / 달리기 / 줄 뛰어넘기 / 숨은 사람 찾기 / 공을 골대에 넣기 / 얼음 위에서 타기 |
| 키보드·화면·마우스·카메라 | 글자 입력 / 글과 그림을 보기 / 화면에서 고르고 누르기 / 사진 찍기 |
| 냉장고·시계·선풍기·세탁기 | 차갑게 보관 / 시간 확인 / 바람 일으키기 / 옷 빨기 |

태극기 문항은 행정안전부 어린이 자료를 직접 연결합니다. NASA·동물원·UNESCO 등 전문 자료가 붙은 항목은 그 원자료를 별도로 연결합니다.

## 한글 확인

바다 → 바 / 다, 토끼 → 토 / 끼, 나무 → 나 / 무, 구름 → 구 / 름, 사과 → 사 / 과, 우유 → 우 / 유, 하늘 → 하 / 늘로 나누어 읽습니다. ㄱ+ㅏ는 가, ㄴ+ㅏ는 나입니다. 음절로 모아 쓴 글자를 하나씩 읽고 세며, 유니코드나 맞춤법 예외를 알 필요는 없습니다.

## 수학 확인

0~10 안의 숫자만 사용합니다. 동그라미를 하나씩 세고, 연필 하나를 더하거나 사과 하나를 빼 보세요. 모든 수학 문항에는 정답을 다시 계산할 수 있는 proof가 들어 있으며 자동 테스트에서 입력과 답의 범위, 정답 계산, 중복을 검사합니다.

## 기록과 모드

키즈에서도 원작의 움직임과 음악을 그대로 사용합니다. 다른 난이도의 문항은 바꾸지 않습니다. 키즈의 오늘의 퀴즈는 키즈에서만 출제하고, 복습도 키즈의 오답만 보여 줍니다. 이전 첫 단계의 문제는 새 문제와 다른 ID를 사용하므로 답 기록이 잘못 연결되지 않습니다. 누적 점수·XP 등은 유지합니다.
