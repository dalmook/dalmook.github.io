# 도파드릴 OX 퀴즈 — 비공식 한국어 변형판

플레이: https://dalmook.github.io/dopa-ox/
키즈 바로 선택: https://dalmook.github.io/dopa-ox/?level=kids
기존 산수판: https://dalmook.github.io/dopa-drill/

기존 산수판은 수정하지 않습니다. 원작의 캐릭터·음악·배경·파티클 엔진을 동일한 파일로 사용합니다. O 또는 왼쪽 화살표는 맞아요, X 또는 오른쪽 화살표는 아니에요, Enter 또는 Space는 다음 문제입니다. 휴대폰에서는 O/X 버튼을 누릅니다.

## 난이도와 키즈 업데이트

**키즈 → 초보 → 중수 → 고수 → 천재 → 초인**. 키즈의 설명은 **초등 1학년**입니다. 키즈를 제외한 이름은 옛 온라인 퀴즈 감성으로 재구성한 것이며, 한게임의 공식 등급표를 재현한 것이 아닙니다. 지능을 평가하지 않습니다. 모든 난이도는 처음부터 선택할 수 있고 경험치 등급은 별개입니다.

첫 단계의 기존 200문항을 키즈 200문항으로 교체했습니다. 전체는 1,200문항이고 초보~초인 1,000문항의 내용·ID·난이도는 그대로입니다. 키즈는 짧은 해요체 문장, 동물·생활 낱말·기초 한글, 10 이내 수 세기·덧셈·뺄셈·비교로 구성합니다. 구구단·분수·소수·시간 환산·역사 인물·수도 암기는 키즈에 없습니다. 이는 제작상의 입문 기준이며 기관에서 공식 인증한 난이도가 아닙니다.

키즈에서는 오늘의 퀴즈와 오답 복습에도 상위 난이도를 섞지 않습니다. 신규 방문자는 키즈로 시작하고 기존 방문자의 선택은 유지합니다. `?level=kids`는 키즈를 명시적으로 선택하는 링크입니다.

## 문제은행

12개 분야, 6개 난이도, 총 1,200문항. 상식·개념·생활 낱말 660문항과 수학 계산 변형 540문항입니다. 수학은 54개 규칙에 10개 사례씩이며 540개의 별도 조사 사실이라고 주장하지 않습니다. 모든 문제에 해설과 출처 또는 확인 방법이 있습니다.

분야: 우주·천문 / 과학·원소 / 동물 / 지구·자연 / 세계지리 / 세계유산·역사 / 한국사·문화 / 국어·언어 / 예술·문학 / 스포츠·놀이 / 컴퓨터·생활 / 수학·논리. 키즈 화면에서는 하늘과 우주, 동물 친구, 쉬운 한글, 숫자 놀이처럼 쉬운 이름을 사용합니다.

10/20/30문제, 분야 복수 선택, 오답 복습, 오늘의 퀴즈, 60초 도전, 문제 도서관·검색·별표, 미션·트로피·컬렉션을 제공합니다. 60초 도전은 실제 읽기·선택 시간만 계산하고 해설·대화상자·백그라운드에서는 멈춥니다. 분야 혼합은 수학 문제의 수가 많아도 한 분야에 치우치지 않도록 균형을 맞춥니다.

## 저장

기록은 `localStorage['dopa-ox-ko-v1']`에만 저장됩니다. 산수판 저장소는 읽거나 변경하지 않습니다. 가입·결제·추적 분석·기록의 서버 전송이 없습니다. 설정에서 JSON 백업을 내보내거나 가져올 수 있습니다.

키즈 교체 후에도 경험치·누적 통계·다른 난이도의 기록은 유지합니다. 은퇴한 옛 1단계 문항은 오답·별표 대기열에서 제외합니다. 새 문제에 옛 답을 잘못 이어 붙이지 않도록 새 ID를 사용합니다.

## 실행과 검사

저장소 루트에서 실행합니다.

```sh
python -m http.server 8765
node --test dopa-ox/tests/*.test.mjs
pip install playwright==1.55.0
python -m playwright install chromium
python dopa-ox/tests/browser.py
```

`http://127.0.0.1:8765/dopa-ox/`로 접속합니다. ES Modules를 사용하므로 `file://` 더블클릭 실행은 지원하지 않습니다.

전용 CI는 `.github/workflows/dopa-ox.yml`입니다. 문항 중복·계산·저장·출제·원작 보존, 초보 이상 1,000문항의 SHA-256 일치, 키즈 문장 길이·수 범위·모드 간 난이도 누출을 검사합니다. 모바일·PC 브라우저 검사와 공개 배포 후 검증 결과·화면을 아티팩트에 보관합니다. 실제 통과 여부는 실행 결과가 기준입니다.
