# 도파드릴 OX 퀴즈 — 비공식 한국어 변형판

기존 산수판 `../dopa-drill/`은 수정하지 않습니다. 원작의 캐릭터·음악·파티클·배경 엔진을 동일한 파일로 가져와, 숫자 계산 대신 **분야별 O/X 판단 → 캐릭터가 답 운반 → 해설 → 다음 문제** 흐름으로 바꿨습니다.

## 플레이

https://dalmook.github.io/dopa-ox/

기존 산수판: https://dalmook.github.io/dopa-drill/

O 또는 왼쪽 화살표: 맞아요. X 또는 오른쪽 화살표: 아니에요. Enter 또는 Space: 해설 확인 후 다음 문제. 휴대폰에서는 큰 O/X 버튼을 누릅니다.

## 내용

12개 분야, 6개 난이도. **총 1,200문항 = 출처를 참고해 작성한 상식·개념 문제 660개 + 계산식으로 검증하는 수학 변형 540개**입니다. 수학 540개는 54개 규칙에 숫자를 바꾼 10개 사례씩이며, 540개의 별도 조사 사실이라고 주장하지 않습니다.

상식 분야마다 60문항, 난이도마다 10문항입니다. 수학은 난이도마다 90문항입니다. 분야 혼합 출제는 분야별 균형을 맞춰 수학 문제의 많은 수가 다른 분야를 밀어내지 않게 했습니다. 한 판에는 같은 문제를 반복하지 않으며, 기존에 안 본 문제를 우선합니다.

분야: 우주·천문 / 과학·원소 / 동물 / 지구·자연 / 세계지리 / 세계유산·역사 / 한국사·문화 / 국어·언어 / 예술·문학 / 스포츠·놀이 / 컴퓨터·생활 / 수학·논리.

### 난이도

바보 → 초보 → 중수 → 고수 → 천재 → 초인.

옛 온라인 퀴즈의 호칭을 참고한 **새 구성**입니다. 옛 한게임의 정확한 공식 등급표를 확인하지 못했으므로 원래 등급표를 재현했다고 주장하지 않습니다. 명칭은 지능 평가가 아니며 난이도는 출제자의 추정치입니다. 분야에 따라 체감 난도가 달라질 수 있습니다. 모든 난이도는 처음부터 고를 수 있고, XP로 얻는 프로필 등급은 별개입니다.

### 모드와 기록

10/20/30문제, 분야 복수 선택, 오답 복습, 매일 같은 구성의 오늘의 퀴즈, 60초 도전, 검색 가능한 문제 도서관과 별표, 미션·트로피·컬렉션을 제공합니다. 60초 도전은 실제 문제 읽기와 선택 시간만 계산하고 해설·대화상자·백그라운드 중에는 멈춥니다.

기록은 `localStorage['dopa-ox-ko-v1']`에만 저장됩니다. 서버 전송·가입·추적 분석·결제는 없습니다. 산수판의 기록을 읽거나 바꾸지 않습니다. 설정에서 JSON 백업을 내보내거나 가져올 수 있습니다. 사생활 보호 모드나 브라우저 정리로 기록이 사라질 수 있으므로 중요한 기록은 백업하세요.

## 출처와 내용 검토

각 문항에 정답·해설·출처 링크가 있습니다. `bank.mjs`의 `SOURCES`가 실제 연결되는 주소의 기준입니다. [출처 안내](SOURCES.md), [수학 검증 방식](MATH.md)을 참고하세요. 사실을 바탕으로 새 문장을 작성했으며 기존 퀴즈 사이트의 문제·해설을 대량 복사하지 않았습니다. 원문 전체·그림·사진·상업적 문제집을 복제하지 않습니다.

법률·의학 조언, 현직 인물, 변동이 잦은 순위·인구·가격 문제는 제외했습니다. 스포츠 규칙은 표시한 자료의 확인 시점을 기준으로 하며 대회별 변형이 있을 수 있습니다. 자동 검사로 사실의 완전한 무오류를 보장하지 않습니다. 오류 제보 버튼은 해당 문제 ID와 출처를 넣은 GitHub 이슈 작성 화면을 열 뿐, 자동으로 제출하지 않습니다.

## 실행과 검사

저장소 루트에서:

```sh
python -m http.server 8765
node --test dopa-ox/tests/*.test.mjs
pip install playwright==1.55.0
python -m playwright install chromium
python dopa-ox/tests/browser.py
```

`http://127.0.0.1:8765/dopa-ox/`에서 실행합니다. ES Modules를 사용하므로 파일을 직접 더블클릭하는 `file://` 방식은 지원하지 않습니다.

전용 CI: `.github/workflows/dopa-ox.yml`. 테스트 성공 여부는 해당 실행 결과를 확인하세요. 정적 문서에 가상의 통과 횟수를 적지 않습니다. CI는 문항 구조·중복·정답 계산·저장·출제 규칙·원본 보존 및 실제 Chromium 브라우저 동작을 검사하고 화면과 JSON 결과를 아티팩트에 보관합니다.
