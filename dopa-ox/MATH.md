# 수학·논리 문항 검증

수학 문제는 외부 문제집에서 가져오지 않은 540개 계산 변형입니다. 초보~초인 450문항은 `data/math.mjs`의 45개 규칙 × 10개 숫자 사례입니다. 키즈 90문항은 `data/kids.mjs`의 9개 쉬운 규칙 × 10개 사례입니다. 원래 수학 파일의 첫 단계 90문항은 실제 문제은행에서 키즈 문항으로 교체됩니다.

각 문제는 `proof.kind`(규칙), `params`(입력), `actual`(계산값), `claim`(문장의 주장값)을 포함합니다. `actual === claim`이면 O, 아니면 X입니다. X의 해설에도 올바른 값을 제시합니다.

## 키즈 90문항

수 세기, 10 이내 덧셈과 뺄셈, 큰 수 고르기, 앞뒤 수, 연필·사과 한 개 더하기·빼기, 하나~열 읽기만 사용합니다. 모든 입력·계산값·주장값은 0~10의 정수입니다. 곱셈·큰 수·시간 환산 사례는 키즈에 나오지 않습니다.

## 초보 이상 검증 규칙

덧셈·뺄셈·곱셈·나눗셈·나머지, 크기 비교, 단위, 반올림, 둘레·넓이·부피, 평균·중앙값·가중평균, 백분율과 분수, 수열, 최대공약수·최소공배수, 거듭제곱, 내각의 합, 조합·순열, 약수·소수, 판별식, 집합의 크기, 나머지 조건을 검증합니다.

대표 공식은 다음과 같습니다.

- 직사각형 둘레 `2(a+b)`, 넓이 `ab`; 직육면체 부피 `abc`, 겉넓이 `2(ab+ac+bc)`.
- 1부터 n까지의 합 `n(n+1)/2`, 제곱의 합 `n(n+1)(2n+1)/6`.
- 볼록 n각형 내각 합 `(n−2)×180°`.
- 최대공약수는 유클리드 알고리즘, 최소공배수는 `ab/gcd(a,b)`.
- 조합 `n!/(r!(n−r)!)`, 순열 `n!/(n−r)!`.
- 부분집합 수 `2^n`; 원소 2개 집합으로 가는 전사함수 수 `2^n−2`.
- 두 집합 합집합은 각 집합 크기 합에서 교집합 크기를 뺍니다. 세 집합은 쌍별 교집합을 빼고 세 집합의 교집합을 더합니다.

주사위는 (1,1)부터 (6,6)까지 직접 열거하고, 나머지 조건은 공통 주기 안에서 직접 탐색합니다. 소수·약수·오일러 피 함수는 작은 정수 범위에서 직접 계산합니다.

계산값은 모두 안전한 정수인지 검사합니다. `tests/engine.test.mjs`는 모든 proof를 다시 계산하고, 조합·순열·약수·소수·수열·나머지 등은 별도의 열거 또는 팩토리얼 방식으로 교차 검사합니다. `tests/kids.test.mjs`는 키즈의 0~10 범위와 간단한 연산만 사용함을 추가 검사합니다. 자동 계산 검사는 교육적 난도나 설명 품질까지 보증하지 않습니다.
