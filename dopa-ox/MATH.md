# 수학·논리 문항 검증

수학 문제는 외부 문제집에서 가져온 것이 아니라 `data/math.mjs`의 54개 규칙에 각각 10가지 숫자를 넣어 만든 540개 변형입니다. 모두 문장, 정답, 풀이, 계산 근거를 포함합니다.

각 문제의 `proof`에는 `kind`(규칙), `params`(입력값), `actual`(계산값), `claim`(문장에서 주장한 값)이 기록됩니다. `actual === claim`이면 O, 다르면 X입니다. X의 해설에도 올바른 계산값을 제시합니다. 판정은 임의의 확률이 아닙니다.

## 검증 규칙

덧셈·뺄셈·곱셈·나눗셈·나머지, 크기 비교, 자리 값, 시간·금액 단위, 반올림, 둘레·넓이·부피, 평균·중앙값·가중평균, 백분율과 분수, 수열의 합, 최대공약수·최소공배수, 거듭제곱, 볼록다각형 내각의 합, 조합·순열, 약수·소수, 판별식, 집합의 크기, 정수 조건을 검증합니다.

대표 공식:

- 직사각형 둘레 `2(a+b)`, 넓이 `ab`.
- 직육면체 부피 `abc`, 겉넓이 `2(ab+ac+bc)`.
- 1부터 n까지의 합 `n(n+1)/2`, 제곱의 합 `n(n+1)(2n+1)/6`.
- 볼록 n각형 내각 합 `(n−2)×180°`.
- 최대공약수는 유클리드 알고리즘, 최소공배수는 `ab/gcd(a,b)`.
- 조합 `n!/(r!(n−r)!)`, 순열 `n!/(n−r)!`.
- 원소 n개 집합의 부분집합 수 `2^n`; 원소 2개 집합으로 가는 전사함수 수 `2^n−2`.
- 두 집합 합집합 `|A|+|B|−|A∩B|`; 세 집합은 쌍별 교집합을 빼고 세 집합의 교집합을 더함.
- 서로 구별되는 주사위 2개의 경우의 수는 (1,1)부터 (6,6)까지 직접 열거.
- 두 나머지 조건은 공통 주기 이내의 음이 아닌 정수를 직접 탐색.
- 소수·약수·오일러 피 함수는 문항에 사용한 작은 정수 범위에서 직접 계산.

계산값은 모두 안전한 정수인지 검사합니다. 떠 있는 소수점 근삿값이 우연히 같거나 다르다는 이유로 정답이 바뀌지 않게 구성했습니다. 문장의 단위와 조건도 함께 읽어 주세요.

`tests/engine.test.mjs`는 모든 proof를 다시 계산하고, 조합·순열·약수·소수·수열·나머지 등은 별도의 열거 또는 팩토리얼 방식으로 교차 검사합니다. 구조 검사는 설명 문장의 교육적 품질까지 자동으로 보증하지는 않습니다.
