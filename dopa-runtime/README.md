# 세 도파 게임 공통 성능 런타임

한국어 산수판 `dopa-drill/`, OX판 `dopa-ox/`, 영단어판 `dopa-word/`에 동일한 성능 관리 방식을 적용합니다. 기존 URL과 게임 조작·점수·저장 방식은 유지합니다. OX의 이전 `?level=kids&v=kids-1` 링크도 현재 프로그램을 불러옵니다.

## 공통 개선

음악은 화면 그리기와 분리하여 25ms 주기로 약 320ms 앞의 음을 Web Audio 시계에 예약합니다. 메인 스레드가 오래 멈추면 타이머도 지연될 수 있으므로 모든 기기에서 출력이 끊기지 않는다고 보장하지 않습니다. 지연된 음을 한꺼번에 몰아서 재생하지 않고 재생 위치에 맞춥니다.

일회성 소리의 오실레이터·필터·게인 연결을 추적하여 재생 종료 후 해제하고, 동시에 유지하는 그래프와 노드 수를 제한합니다. 원작 악기·멜로디·공유 리버브/딜레이 버스는 유지합니다. 브라우저의 기존 자동 정리가 전혀 작동하지 않았다는 주장은 하지 않습니다.

보이지 않는 배경과 빈 파티클 화면은 불필요하게 다시 그리지 않습니다. 배경 해상도와 갱신 주기, 보조 캐릭터 수, 파티클 수를 실행 부하에 따라 줄입니다. 주인공과 팔이 정답을 가져오는 동작은 원작 경로를 유지합니다. 박자에 따른 CSS 변수는 필요한 카드/자판에만 갱신합니다. 큰 정답 축하 효과는 콤보·마지막 문제 등 이정표에서 사용하고 기본 정답 반응은 유지합니다.

백그라운드에서는 오디오 작업을 쉬고 돌아오면 재생 시각을 다시 맞춥니다. 문서가 종료되면 타이머와 오디오 자원을 정리합니다. 산수판의 오프라인 영상/오디오 캡처 모드는 원래의 결정적 예약 방식을 유지합니다.

## 각 사이트의 설정

톱니바퀴 → **성능 설정**에서 선택합니다.

- **자동 조절 (권장)**: 기본은 균형 모드이며 지속적으로 느린 프레임이 감지되면 장식 부하를 줄입니다.
- **고화질**: 원작에 가까운 장식 밀도를 우선합니다.
- **가볍게**: 배경과 보조 효과를 줄이고 주인공·팔 동작은 유지합니다.

기존 **움직임 최소화**는 별도 설정이며 애니메이션을 생략하고 싶은 경우 사용합니다. 성능 선택은 각 게임의 `dopa-*-performance-v1` 키에만 저장합니다. 개인 단어, 오답, 점수, 학습 기록을 삭제할 필요가 없습니다.

## 그대로 두는 데이터

`protected-files.json`의 53개 기준 파일과 SHA-256을 검증합니다. 원작 오디오·캐릭터·효과 엔진 원본, 라이선스, 산수 출제/점수/저장 모듈, OX 문제은행과 키즈 난이도, 영단어 기본·개인·공유 데이터 계약 및 공개 마트 단어장을 포함합니다. 사용자 단어·학습 기록을 테스트에 가져오거나 공개 저장소로 올리지 않습니다.

과거 ‘다른 게임 폴더는 하나도 수정하지 않는다’ 검사는 이번 사용자의 세 사이트 공통 런타임 변경 요청과 충돌하므로, 변경하지 않아야 하는 데이터·게임 규칙·원작 자산을 명시적으로 해시 검증하는 방식으로 바꾸었습니다. 다른 기능 검사는 그대로 유지합니다.

## 검증 범위와 한계

`tests/runtime.test.mjs`와 기존 파생판의 테스트로 규칙·원작 보존·스케줄러·자원 정리·오프라인 캡처 호환성을 검사합니다. `tests/three_games.py`는 새 브라우저에서 각 실제 게임 한 판을 UI 입력으로 끝내고 기록 보존, 원래 URL, 모바일/PC 조작, 실제 오디오를 켠 합성 고연출 부하와 백그라운드 복귀를 확인합니다. 영단어판의 실제 팔 경로 검사를 별도로 실행합니다.

기능 브랜치 실행 https://github.com/dalmook/dalmook.github.io/actions/runs/36562216636 에서 단위/모델 검사 **187개**, 세 게임 브라우저 검사 **52개**, 원작 영단어 팔 동작 검사 **57개**가 모두 통과했습니다. 실제 보고서·화면을 담은 아티팩트는 `11030501969`이며 SHA-256은 `46dce0e4df0d442467edf4a514511e0a322c7b677a09b4b94f0ad6327e5e76f7`입니다. 공개 배포 확인은 이 결과와 별개로 main에서 다시 수행합니다.

부하 수치는 CI Chromium 환경의 관찰이며 실제 휴대폰 FPS나 스피커/블루투스 출력의 파형 측정이 아닙니다. 원래 있던 모든 브라우저·기기·장시간 세션 문제를 해결했다는 의미도 아닙니다. 실제 통과 횟수와 실패는 `.github/workflows/dopa-all-performance.yml` 실행 보고서에 남깁니다. 공개 배포 후에는 핵심 파일 14개를 커밋과 비교하고 동일한 사이트별 검사를 다시 실행합니다.
