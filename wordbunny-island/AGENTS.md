# WordBunny Island — 작업 규칙

## 프로젝트 경계
- 완전히 새로운 독립 앱이다. `heather_word`를 수정/확장/마이그레이션하지 않는다.
- 배포 위치는 `dalmook/dalmook.github.io` 저장소의 `wordbunny-island/` 독립 폴더다. 이 폴더 밖의 기존 홈페이지/게임과 `heather_word`는 수정하지 않는다. 전용 저장소는 생성하지 않았다.
- 저장소·Pages를 실제로 생성/검증하기 전에는 생성됐거나 배포됐다고 말하지 않는다.
- 사용자가 요청하지 않은 저장소 공개/비공개 변경, 원본 삭제, 강제 푸시를 하지 않는다.

## 사용 대상과 제품
초등학생의 그림-영어-뜻 연결, 듣기, 짧은 모험, 서로 다른 놀이, 오답 복습, 보상을 결합한다. 보호자가 직접 단어/사진을 넣고 GPT를 통해 저장소의 콘텐츠만 갱신할 수 있어야 한다. 한국어 설명은 쉽게, 영어는 단어와 짧은 예문에 사용한다. 캐릭터는 이 프로젝트의 원본 흰 토끼다.

## 구현 계약
- 런타임 외부 패키지/CDN/광고/분석 추적/로그인/유료 API가 없는 정적 웹앱을 유지한다.
- `js/core.js`는 단위검사 가능한 순수 데이터/학습 로직이다.
- `js/app.js`는 저장, 편집, 게임, 라우팅을 연결한다.
- IndexedDB 이름은 `wordbunny-island-v1`이다. 브라우저 저장소를 초기화하는 코드를 임의로 추가하지 않는다.
- 서비스 워커는 자신의 scope에 속한 캐시만 변경한다. 같은 origin의 다른 앱 캐시는 지우지 않는다.
- 개인 기록은 기기별 저장이다. 공개 단어팩에 이름, 학습 기록, 얼굴사진, 자격증명, 토큰을 넣지 않는다.
- 기기 저장/백업과 GitHub 콘텐츠 게시를 구별한다. 앱 내 편집은 자동 GitHub 업로드가 아니다.
- 단어 ID는 학습 기록 키다. 같은 단어의 내용 수정 시 유지한다.
- 성공 안내는 저장 완료 후 표시한다. 저장 실패를 성공으로 바꾸지 않는다.
- 사진은 직접 선택, 검증, 크기 축소 후 저장한다. 임의의 외부 이미지 URL은 받지 않는다.
- 음성 인식/발음 판정을 구현하지 않은 상태에서 판정됐다고 표시하지 않는다.
- 일중 반복으로 숙련도를 부풀리지 않는다. 오답/힌트는 분리 집계한다.

## 콘텐츠 작업
먼저 `content/AGENTS.md`를 읽는다. 단어 추가 요청에서 UI와 게임 코드는 임의 변경하지 않는다.

## 검증
변경 후 다음을 실행한다.
```
node --check js/app.js
node --check js/core.js
node --check js/art.js
node scripts/validate-content.cjs
node --test tests/core.test.cjs
python scripts/build.py
```
가능하면 브라우저에서 편집, 사진 등록, 복습, 게임 완주, 백업/복원, 모바일 화면을 검사한다. 실제 브라우저 검증과 DOM 시뮬레이션을 구별해서 기록한다. 단어를 바꾸면 폴더 버전과 내장 단일 HTML의 수가 맞아야 한다.

## 보고
어떤 파일을 바꿨는지, 검증 결과, 실제 커밋/배포 상태를 알려 준다. 실행하지 않은 테스트 수, 존재하지 않는 링크/커밋/배포 성공을 만들지 않는다.
