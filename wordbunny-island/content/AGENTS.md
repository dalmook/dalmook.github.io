# GPT 단어·이미지 업데이트 규칙

이 디렉터리는 독립 앱 **WordBunny Island**의 콘텐츠다. `heather_word`에는 쓰지 않는다. 상위 `AGENTS.md`가 우선한다.

## 먼저 확인
1. 현재 저장소와 기존 `manifest.json`, 대상 팩, 중복 ID를 읽는다.
2. 사용자가 첨부한 영어·한글 뜻·사진을 원자료로 사용한다. 단어 이미지가 없으면 이미지 생성을 완료했다고 주장하지 말고 공란으로 둔다.
3. 아이 얼굴, 이름표, 학교, 주소, 민감한 사진은 공개 저장소에 올리지 않는다. 공개 여부가 불명확하면 확인한다.
4. 외부 이미지 무단 복제, API 키, 기기 백업 JSON, 학습 기록을 커밋하지 않는다.

## 파일 형식
`manifest.json`의 `schemaVersion`은 1이며 `packs`가 팩 목록이다.
팩 경로는 `content/packs/<영문숫자_하이픈>.json`, 이미지 경로는 `content/images/...`다. 경로와 파일 이름 대소문자를 일치시킨다.

팩 예시:
```json
{
  "schemaVersion": 1,
  "id": "weekly-01",
  "title": "이번 주 단어",
  "words": [
    {
      "id": "weekly-01-apple",
      "en": "apple",
      "ko": "사과",
      "category": "이번 주 단어",
      "level": 1,
      "image": "content/images/weekly-01/apple.webp",
      "example": "I like apples."
    }
  ]
}
```
실제 이미지 파일이 없으면 `image`는 빈 문자열로 둔다. 위 예시 파일이 실제로 있다고 가정하지 않는다.

## ID와 중복
- 영문·숫자·밑줄·하이픈으로 유일한 ID를 지정한다. 기존 학습 기록 유지가 필요하므로 같은 단어는 ID를 유지한다.
- 영어+한글 뜻이 같은 항목은 새로 만들지 말고 기존 항목과 비교해 보완한다.
- 동음이의어 등 다른 뜻은 별도 ID로 가능하다. 게임의 선택지 중복 의미 규칙을 유지한다.
- 다른 단어로 바꾸는 경우 새 ID를 사용한다.
- 한 팩은 최대 1,000단어, 저장소 전체 콘텐츠는 최대 10,000단어다. 큰 추가는 팩으로 나눈다.
- 사용자가 사진만 바꾸라고 하면 단어/뜻/기존 다른 사진을 변경하지 않는다.

## 사진
- JPG, PNG, WebP, 저장소의 검토된 SVG를 사용한다. 사진은 가능하면 긴 변 960px 안팎으로 최적화한다.
- 메타데이터와 얼굴/이름/위치 노출 여부를 확인한다. 이미지에 임의 외부 호출/스크립트를 넣지 않는다.
- `image`에 원격 URL, 절대경로, `..`, base64를 커밋하지 않는다.
- 원본 소스 그림을 재생성하는 `make_assets.py`를 콘텐츠 추가마다 실행하지 않는다. 같은 이름의 사용자 그림을 덮어쓸 수 있다.

## ZIP 처리
앱에서 내보낸 ZIP은 활성 단어 전체 스냅샷이다. 다음 순서로 처리한다.
- ZIP의 단어 ID/사진을 현재 저장소와 비교한다.
- 단순 추가 요청이면 기존 manifest를 유지하고 필요한 항목만 병합한다.
- 숨긴 단어가 ZIP에 없다는 이유만으로 원격 단어를 삭제하지 않는다.
- 대체/삭제는 사용자의 명시적 지시가 있을 때만 한다.
- 내보내기 JSON에 학습 기록을 추가하지 않는다.

## 검증과 산출물
```
node scripts/validate-content.cjs
node --test tests/core.test.cjs
python scripts/build.py
```
팩을 새로 만들면 manifest에 등록한다. 생성된 `js/starter.js`, `sw.js`, `OPEN_WORD_BUNNY.html`까지 반영한다. 경로 누락, 중복 ID, 잘못된 한글 인코딩을 확인한다. 실제 앱에서 새 단어의 카드/그림/철자 게임을 확인한다. 이미지 없는 단어는 적절한 대체 문제가 나오는지 확인한다.

최종 보고에는 추가/수정/제외 수, 파일 위치, 검증 결과, 실제 배포 결과를 구분해 쓴다.
