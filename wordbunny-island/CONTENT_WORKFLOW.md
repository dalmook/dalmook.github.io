# 단어와 사진만 GPT로 업데이트하기

현재 배포 대상은 `dalmook/dalmook.github.io` 저장소의 `wordbunny-island/` 폴더입니다. 아래 요청에 단어와 사진을 첨부하세요.

> `dalmook/dalmook.github.io` 저장소의 `wordbunny-island/AGENTS.md`와 `wordbunny-island/content/AGENTS.md`를 먼저 읽어 줘. 첨부한 단어·한글 뜻·사진을 `wordbunny-island/content/` 아래에 새 단어팩으로 추가해 줘. 기존 단어, 기존 사진, 학습 ID는 유지하고 중복은 비교해서 처리해. 사진은 해당 단어와 정확히 매칭하고 저장소 내부 이미지 파일로 넣어 줘. 얼굴·실명·학교 정보가 있는 사진은 공개 게시하지 말고 알려 줘. manifest 등록, 콘텐츠 검증, 단위 테스트, 단일 HTML 재빌드까지 해 줘. 실행하지 않은 검증이나 배포를 완료했다고 말하지 마. 기존 `heather_word` 저장소는 수정하지 마.

## 앱에서 먼저 편집한 내용 보내기

앱의 보호자 공간에서 `GitHub용 ZIP`으로 내보낸 파일을 첨부하세요.

> 이 ZIP은 워드버니 아일랜드의 전체 콘텐츠 스냅샷이야. 현재 저장소와 ID별로 비교해서 새 단어와 수정된 사진을 병합해 줘. ZIP에 없는 기존 단어를 삭제하지 말고, manifest도 무조건 덮어쓰지 마. 개인 백업이나 학습 기록은 커밋하지 마. 단어팩과 이미지 경로를 검증하고 다시 빌드해 줘.

## 로컬 수정본 우선 규칙

앱에서 수정한 단어는 기기에 별도 수정본이 남습니다. GitHub에서도 같은 ID를 바꿔도 해당 기기에서는 로컬 수정본이 우선 표시됩니다. 서로 다른 내용을 동시에 관리하지 않으려면 편집 기준을 GitHub 또는 기기 중 하나로 정하세요. 같은 단어를 다른 단어로 바꾸면서 ID를 재사용하지 마세요.

## 파일 3종을 혼동하지 않기

| 파일 | 목적 | 공개 저장소 |
|---|---|---|
| `wordbunny-content-*.zip` | 단어와 사진 업데이트 | 사진을 검토한 뒤 병합 |
| `wordbunny-backup-*.json` | 기기 단어·사진·학습 기록 복원 | 올리지 않기 |
| `OPEN_WORD_BUNNY.html` | 내장 콘텐츠가 있는 실행판 | 원본 콘텐츠 범위 확인 후 가능 |

내장 단일 HTML은 저장소의 단어 변경을 자동 다운로드하지 않습니다. `python scripts/build.py`로 재생성해야 합니다. 폴더 버전 `index.html`은 온라인에서 manifest를 확인합니다.
