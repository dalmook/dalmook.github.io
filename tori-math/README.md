# 토리의 수학탐험

흰 토끼 토리와 함께하는 한국어 수학 액션 웹게임입니다.

**플레이:** https://dalmook.github.io/tori-math/

## 실제 구현된 기능

- 독립 관절로 그리는 흰색 토끼: 긴 귀, 스카프, 팔, 다리, 무기 애니메이션. 돌진, 잔상, 별빛 베기, 당근 회오리, 빙결, 별똥별 각성.
- 6개 세계, 48개 스테이지. 세계별 8단계 중 마지막은 보스 스테이지. 각 세계의 첫 단계는 잠그지 않습니다.
- 24개 연산 주제: 덧셈·뺄셈·곱셈·나눗셈, 소수, 분수, 최대공약수, 백분율, 비례식. 문제는 매번 생성되며 같은 크기의 분수도 정답으로 인정합니다.
- 자유 연습, 오답 복습, 60초 질주, 8문제 난이도 추천. 일반 모험에는 시간 제한이나 게임 오버가 없습니다.
- 콤보에 따라 레이어가 추가되는 자체 합성 음악과 효과음. 음원 파일을 다운로드하지 않습니다.
- 별사탕, 경험치, 단계별 별점, 일일 목표, 5종 탐험복, 6종 업적. 현금 결제나 광고는 없습니다.
- 모바일 터치 숫자판과 PC 키보드 조작. 작은 화면에서는 게임에 집중할 수 있도록 탐색 메뉴를 숨깁니다.
- 음소거, 음량, 움직임 강도 설정과 운영체제의 움직임 줄이기 설정 대응.
- 브라우저 자동 저장, JSON 기록 내보내기/가져오기, 오류·저장 차단 처리, 초기화 확인.

## 조작

숫자를 입력한 뒤 **Enter** 또는 **정답 확인**을 누릅니다. Backspace는 지우기, Space는 별빛 100을 모았을 때 각성, Esc는 일시 정지입니다. 소수점은 `.`, 분수는 `/`로 입력합니다. `1/2`, `2/4`, `0.5`는 같은 답으로 인정합니다.

각성은 연출 스킬이며 학습 문제를 건너뛰지 않습니다. 오답 뒤에는 다시 풀 수 있고, 힌트와 풀이도 볼 수 있습니다. 틀렸거나 풀이를 본 문제는 복습 목록에 남으며, 이후 첫 시도에 맞히면 목록에서 빠집니다. 모험을 중단해도 푼 문제의 학습 기록은 보존되지만, 미완료 스테이지의 완료 보상은 지급하지 않습니다.

## 실행

빌드와 외부 패키지 없이 동작합니다. ES Modules를 사용하므로 HTML 파일을 직접 더블클릭하지 말고 정적 서버로 실행하세요.

```bash
cd tori-math
python -m http.server 8000
# http://localhost:8000
```

## 테스트

```bash
node --test tests/math.test.mjs
python -m pip install playwright==1.55.0
python -m playwright install chromium
python tests/browser.py
```

단위 테스트는 24개 생성기 각각 500개, 총 12,000개 문제를 포함합니다. 브라우저 테스트는 실제 HTTP 서버와 ES Module 로딩으로 실행하며, 키보드/터치 플레이, 모든 문제 유형, 오답·풀이·복습, 보상·옷장, 스테이지 해금, 진단·타이머·일시정지, 화면 크기와 런타임 오류를 확인합니다. 제한된 오프라인 렌더링 환경에는 `--inline`이 있으며, 이는 HTTP 통합 테스트를 대체하지 않습니다.

GitHub Actions에서 단위 테스트·브라우저 검사와 스크린샷을 남깁니다. 새 게임은 독립된 `tori-math/` 폴더이며, 기존 `dopa-drill/`과 다른 사이트 파일을 변경하지 않습니다.

## 파일 구조

- `index.html`, `style.css`: 반응형 한국어 화면과 접근 가능한 컨트롤
- `app.mjs`: 세션, 화면 전환, 입력, 보상, 일시정지와 저장 흐름
- `math.mjs`: 연산 생성, 정답 판정, 세이브 검증과 성장 규칙
- `scene.mjs`: 오리지널 Canvas 캐릭터 리깅, 배경, 적과 액션 효과
- `audio.mjs`: Web Audio 기반 오리지널 배경 음악과 효과음
- `tests/`: 수학·저장 단위 테스트와 브라우저 플레이 테스트

## 출처와 범위

grmchn/dopa-drill의 '문제를 풀수록 연출이 신나는 학습'이라는 아이디어를 참고했습니다. 해당 프로젝트의 코드, 캐릭터, 로고, 폰트, 음원은 이 게임에 복사하지 않았습니다. 던전앤파이터의 캐릭터·음원·이미지 등 상용 게임 자산도 포함하지 않습니다. 이 프로젝트의 토리는 특정 인형 브랜드의 공식 캐릭터나 제휴 상품이 아닙니다. 그림은 별도 생성 이미지를 넣은 것이 아니라 코드로 그리는 벡터 리깅 캐릭터입니다.

학년 구분은 연습 난이도 안내입니다. 한국 교육과정 전체, 모든 단원, 서술형 풀이, 정식 학력 진단을 제공한다는 뜻은 아닙니다. 8문제 추천은 가벼운 출발점 제안입니다.

## 개인정보와 저장

계정과 백엔드가 없으며 학습 기록은 `localStorage`의 `tori-math-adventure:v1`에 저장합니다. 게임 코드에는 분석·추적·광고 도구와 외부 API 호출이 없습니다. GitHub Pages 호스팅의 일반적인 접속 로그 정책은 별개입니다. 기기 간 자동 동기화는 없고, 기록 파일로 옮길 수 있습니다. 브라우저의 사이트 데이터를 삭제하면 저장 기록이 사라집니다.
