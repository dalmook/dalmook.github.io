# 음악·화면의 지속 부하 개선

원작 악기·멜로디·캐릭터·팔 동작 파일을 교체하지 않고, 영단어판의 실행 방식을 개선합니다. 단어·뜻·공개 목록·개인 학습 기록은 변경하지 않습니다.

## 확인된 구조와 개선

기존에는 매 화면 프레임에서 음악을 120ms 앞까지 예약했습니다. 그래픽 작업이 밀리면 다음 음의 예약도 지연될 수 있었습니다. 이제 별도의 25ms 타이머로 약 320ms 앞의 음을 Web Audio 시계에 예약합니다. 매우 긴 메인 스레드 정지는 타이머도 늦출 수 있으므로 무제한 끊김 방지를 보장하지 않습니다. 늦은 음을 한꺼번에 몰아서 재생하는 동작은 피합니다.

원작 synth에서 생성되는 일회성 오실레이터·필터·게인·이펙트 전송 노드는 하나의 음 단위로 추적합니다. 마지막 소스의 재생 종료 이후 연결을 명시적으로 해제하며, 공유 리버브·딜레이 버스는 남겨 잔향을 유지합니다. 동시 음 그래프와 노드 수에 상한을 둡니다. 이 조치는 기존 브라우저의 자동 수거가 전혀 작동하지 않았다고 단정하는 뜻이 아닙니다.

매 문제 정답에 일반 정답 효과와 큰 클리어 효과를 모두 겹치던 동작은 조정합니다. 일반 정답 반응은 유지하고 큰 클리어 효과는 5콤보 등 이정표에 사용합니다. 원작 BGM의 악기와 곡 구성은 그대로 사용합니다.

배경·보조 캐릭터·파티클은 처리량에 따라 갱신 빈도·해상도·개수를 조절합니다. 주인공과 정답을 집는 팔은 원래 프레임 경로를 사용합니다. 보이지 않는 배경과 빈 파티클 캔버스를 매 프레임 다시 그리지 않습니다. 박자에 따라 바뀌는 CSS 변수는 문서 전체 대신 카드에만 적용합니다.

뜻 고르기 팔 동작에서 위치 계산은 스크롤·화면 회전 등 실제 배치가 바뀔 때만 갱신합니다. 이동 라벨은 매 프레임 left/top을 바꾸는 대신 transform을 사용합니다.

## 설정

설정 → 성능 설정:

- **자동 조절 (권장)**: 장식 효과를 균형 있게 표시하고 지속적인 프레임 지연이 감지되면 가볍게 조절합니다.
- **고화질**: 원작 수준의 배경·장식 밀도를 우선합니다.
- **가볍게**: 보조 효과를 줄입니다. 움직임 설정이 켜져 있으면 주인공과 팔 동작은 유지됩니다.

별도의 ‘움직임 최소화’를 선택하면 기존대로 애니메이션을 생략합니다. 성능 선택은 `dopa-word-performance-v1`이라는 별도 키에만 저장되며 기존 단어장 저장을 지우거나 바꾸지 않습니다.

## 측정과 한계

`tests/performance_browser.py`는 동일한 이전 커밋과 변경본을 Chromium 390×844, DPR 2, CPU 4배 지연 환경에서 비교합니다. 단계별 프레임 간격, 늦은 음악 예약, 배경 그리기 횟수, 문서 전체 스타일 변경, AudioNode 생성·수거 수와 활성 임시 노드 수를 기록합니다. 고부하 단계는 최대 연출 상태에서 1.4초마다 축하 반응을 주는 합성 부하입니다. 사용자 실제 기기와 같은 FPS나 실제 오디오 출력의 무결성을 보증하지 않습니다.

재생 후 임시 음 그래프가 0개로 정리되는지, 타이머가 중복 생성되거나 종료 후 남는지, 그래픽 갱신 없이도 음악 예약이 진행되는지를 검사합니다. 원작 팔의 실제 경로·터치·키보드·정답 판정 테스트도 유지합니다. 실제 통과 여부와 측정값은 GitHub Actions의 결과·아티팩트가 기준입니다.
