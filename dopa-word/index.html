어떤 카테고리를 배울까요?

기본·내 카테고리를 모두 보여 줘요. 카테고리를 선택하면 이전 단어장·길이 제한을 풀고 해당 단어를 전부 학습해요. 여러 개도 선택할 수 있어요.

단어를 모아 축제를 열어요!

스펠링 맞히기: 한글 뜻을 읽고 화면 자판의 알파벳을 차례로 눌러요. PC 키보드로도 입력할 수 있어요. 칸을 다 채우면 자동 확인해요.

뜻 고르기: 영어 단어를 보고 한글 뜻 네 개 중 하나를 골라요. PC에서는 1~4로 선택해요.

틀려도 게임은 계속돼요. 힌트와 정답 보기를 쓴 단어는 복습에 모이고, 스스로 맞히면 콤보가 올라가요.

내 단어 등록: 단어장 관리에서 하나씩 저장하거나 엑셀 두 열을 붙여 넣어요. 기본 단어와 내 단어를 섞거나 따로 배울 수 있어요. 직접 등록한 카테고리도 홈의 카테고리 선택에 표시돼요. 단어장에서 카테고리를 고르면 두 모드의 전체 학습 버튼을 사용할 수 있어요.

단어가 적어도 뜻 고르기가 가능하도록 오답 보기는 기본 단어장에서 보충해요. 비슷한 뜻은 겹치지 않게 거르지만, 직접 등록한 여러 뜻은 확인해 주세요.

기록은 현재 브라우저에만 저장돼요. 다른 방문자에게 자동 공유되지 않지만 같은 브라우저 프로필을 쓰는 사람은 볼 수 있어요. 다른 기기로 옮기거나 직접 공유할 때는 설정의 JSON 백업 또는 내 단어 CSV 파일을 사용해요. 공유받는 사람은 그 파일 내용을 볼 수 있어요. 발음 기능은 브라우저의 영어 음성이 있어야 사용할 수 있어요.
