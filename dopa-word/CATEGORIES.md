# 카테고리 전체 학습 · 저장 범위

## 수정된 카테고리 선택

홈의 **카테고리 선택**에는 현재 ‘기본 단어/내 단어’와 단어 길이 조건에 관계없이 기본 카테고리와 내가 등록한 카테고리가 모두 나옵니다. 내 단어가 있는 카테고리는 목록 위쪽과 홈의 **내가 등록한 카테고리**에도 표시합니다.

카테고리를 선택하면 이전에 설정했던 기본 단어 전용·짧은 단어 제한을 해제하고, 그 카테고리를 선택한 상태로 **전체 단어 학습**을 설정합니다. 예를 들어 내가 만든 카테고리에 20단어가 있으면 그 20개를 중복 없이 학습합니다. 스펠링·뜻 고르기를 전환해도 선택한 카테고리를 유지합니다.

한 판을 짧게 나누려면 홈의 **한 판 문제 수**에서 10·20·30문제로 바꿀 수 있습니다. 전부 배우려면 **전체 단어 학습**을 선택하세요. 수동으로 길이 제한을 다시 걸면 카테고리 전체 수와 현재 조건의 단어 수를 각각 보여 줍니다. **이 카테고리 전체 단어로 바꾸기**로 제한을 한 번에 해제할 수 있습니다.

## 단어장에서 바로 시작

**단어장 관리 → 카테고리 선택 → 스펠링 전체 학습 / 뜻 고르기 전체 학습**.

이 버튼은 해당 카테고리의 모든 단어를 사용합니다. 관리 화면에서 검색어로 목록을 일부만 보고 있더라도 학습 대상을 그 검색 결과로 줄이지 않습니다. 단어장이 없는 카테고리를 임의로 만들거나 다른 카테고리의 정답 단어를 섞지 않습니다. 객관식의 오답 보기는 여전히 기본 단어에서 보충할 수 있습니다.

개별 등록·일괄 등록 후에는 저장한 단어의 카테고리를 홈 학습 대상으로 선택합니다. 여러 카테고리를 일괄 등록하면 등록된 카테고리들을 함께 선택합니다. 오류 행과 중복 건너뛰기 규칙은 이전과 동일합니다. 기존 단어를 새 카테고리로 옮기려면 단어 수정 또는 명시적인 덮어쓰기를 사용하세요.

카테고리가 선택되어 있을 때 복습은 그 카테고리 안에서 해당 모드의 오답만 보여 줍니다. 다른 카테고리의 오답 기록은 삭제하지 않습니다. 카테고리 선택을 해제하면 전체 복습으로 돌아갑니다.

## 다른 사람이 볼 수 있나요?

사용자 단어와 기록은 현재 기기·브라우저 프로필의 `localStorage['dopa-word-ko-v1']`에 저장됩니다. 사이트에 접속한 다른 사람의 기기로 자동 공개·전송·동기화하지 않습니다. 기본 단어 240개는 사이트에 포함된 공개 데이터지만, 입력한 개인 단어를 기본 단어 파일이나 GitHub에 추가하지 않습니다.

동일한 기기에서 동일한 브라우저 프로필을 함께 쓰는 사람은 그 안의 단어장을 볼 수 있습니다. 비밀번호가 걸린 비밀 보관함은 아닙니다. 또한 브라우저 저장소는 웹사이트의 origin(프로토콜·호스트·포트)을 기준으로 하므로 폴더별로 보안 격리되는 것은 아닙니다. 이 앱은 산수·OX판의 저장 키를 읽거나 수정하지 않습니다.

누군가에게 직접 **내 단어 CSV** 또는 **전체 기록 JSON** 파일을 전달하면 그 사람은 파일 내용을 보고 가져올 수 있습니다. 단어만 공유하려면 CSV가 적합하고, JSON은 학습 기록과 설정도 포함하므로 전달 전에 내용을 확인하세요. 이 수정은 자동 공유나 서버 저장 기능을 추가하지 않습니다.

저장 방식 참고: https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage

## 기록 보존과 검증

기존 저장 키와 v1 JSON 형식을 유지합니다. 개인 단어·경험치·복습 기록은 초기화하지 않습니다. 전체 학습의 30개 초과 결과도 백업·재접속 때 잘리지 않도록 했습니다. 긴 세션의 진행 점은 한 번에 30개만 표시하고 문제 번호는 전체 분모를 유지합니다.

카테고리 테스트는 **테스트용으로 생성한 단어**를 별도의 새 브라우저 프로필에 저장해서 실행합니다. 사용자의 실제 브라우저 단어장을 가져오거나 공개 저장소에 복사하지 않습니다. 두 모드에서 35개 전체 완주, 복습 범위, 30개 초과 기록 보존, 기본 필터 아래의 카테고리 발견, 개별·일괄 등록 후 선택, 다른 방문자와의 저장 분리, 모바일 화면을 검사합니다. 실제 통과 여부는 GitHub Actions 보고서를 확인합니다.
