# 도파드릴 영단어 — 비공식 한국어 변형판

## 공개 단어장 업데이트

이제 홈의 **공개 단어장**에서 다른 사람이 공개한 단어를 로그인 없이 보고 두 모드로 학습할 수 있습니다. **내 단어 공유하기**는 선택한 카테고리만 즉시 링크로 전달하거나 GitHub Actions 공개 목록에 등록합니다. 공개 목록 게시·수정은 운영자 GitHub 로그인과 제출이 필요하고, 읽기·학습에는 로그인이 필요 없습니다. 개인 저장과 공개 등록은 구분되며 점수·오답 기록은 공개하지 않습니다. 상세한 공개·수정·내리기와 보관본 안내는 [SHARING.md](SHARING.md)를 확인하세요.

플레이: https://dalmook.github.io/dopa-word/

기존 산수판 https://dalmook.github.io/dopa-drill/ 과 OX판은 수정하지 않고 별도 폴더에 추가합니다. 원작의 캐릭터·팔로 글자를 옮기는 동작·축하 연출·파티클·배경·Web Audio 음악을 그대로 사용합니다. 새 캐릭터나 이미지 위주의 재설계가 아닙니다.

## 두 가지 모드

**스펠링 맞히기**는 한글 뜻을 보여 주고 화면의 QWERTY 자판에서 알파벳을 차례로 누르게 합니다. PC 키보드 A~Z, Backspace, Enter도 지원합니다. 칸이 모두 차면 자동 확인합니다. 영어의 대소문자는 구분하지 않고, `ice cream`, `t-shirt`, `don't`의 공백·기호는 문제에 미리 표시합니다. 사용자는 알파벳만 입력합니다.

**뜻 고르기**는 영어 단어와 한글 뜻 네 개를 보여 줍니다. 클릭·터치 또는 숫자 1~4로 고릅니다. 잘못 고른 보기는 표시한 뒤 다시 선택할 수 있습니다. 단어가 적은 개인 단어장에서도 네 보기를 만들도록 기본 단어장에서 오답 보기를 보충합니다. 학습할 정답 단어를 기본 단어로 바꾸는 것은 아닙니다.

틀리거나 힌트를 사용해도 게임은 끝나지 않습니다. 정답을 배울 때까지 이어가고 진행할수록 원작의 연출과 음악이 고조됩니다. **힌트·정답 보기·오답 후 정답은 ‘스스로 정답’ 점수와 콤보에 포함하지 않고 복습에 넣습니다.** 두 모드의 복습과 익숙함 기록은 따로 관리합니다.

발음 버튼은 브라우저의 영어 음성 합성을 사용합니다. 지원하는 영어 음성이 없는 기기에는 안내를 표시합니다. 발음 음색·가용성은 기기와 브라우저에 따라 다르며 게임 자체 음원에 영어 발음 파일이 들어 있는 것은 아닙니다.

## 기본 240단어

동물 친구, 맛있는 음식, 가족과 사람, 우리 몸, 색과 모양, 우리 집, 학교와 물건, 자연과 날씨, 움직임, 느낌과 모습, 시간과 숫자, 장소와 탈것 — 12개 주제에 각 20개씩 제공합니다.

단어와 짧은 한국어 뜻을 직접 선정했습니다. 상업용 사전·문제집·이미지를 통째로 복제하지 않았습니다. 뜻은 이 단어장에서 학습하는 기본 의미이며 모든 사전적 의미를 나열한 것이 아닙니다. 특정 교육과정의 공식 인증 목록이라고 주장하지 않습니다. `words.mjs`에서 기본 단어를 수정하거나 추가할 수 있습니다.

첫 단어 / 기초 / 도전은 주로 철자 길이를 기준으로 나눕니다. 학년 등급이 아닙니다. 전체를 선택하면 길이에 관계없이 출제합니다. 주제는 여러 개를 선택할 수 있고 한 판은 10·20·30문제로 설정합니다. 조건에 맞는 단어가 적으면 실제 개수만큼 진행하며 같은 판에서 중복 출제하지 않습니다.

## 한 단어씩 등록

단어장 관리 → 한 단어 등록 → 영어 / 한글 뜻 / 단어장 이름 → 저장하기.

영어는 1~40자이고 알파벳과 단어 사이 공백·하이픈·아포스트로피를 지원합니다. 뜻은 100자, 단어장 이름은 30자 이내입니다. 개인 단어는 최대 3,000개입니다. 뜻을 여러 개 적을 때는 세미콜론으로 구분할 수 있습니다.

동일한 영어 단어를 다시 저장하면 내 단어의 뜻을 수정합니다. 기본 단어와 영어가 같으면 합쳐서 볼 때 내 뜻을 우선 사용합니다. 삭제하면 원래 기본 단어의 뜻으로 돌아갑니다. 뜻이 바뀐 단어의 학습 기록은 초기화하여 예전 정답이 새 뜻에 잘못 연결되지 않게 합니다. 다른 단어의 기록과 누적 XP는 유지합니다.

등록 후 **내 단어로 바로 연습**을 누르거나 홈의 학습 단어장을 **내 단어만** 또는 **기본 + 내 단어**로 바꿉니다. 이 선택은 두 모드에 모두 적용됩니다.

## 여러 단어 한 번에 등록

엑셀에서 영어와 뜻 두 열을 복사하고, 단어장 관리 → 일괄 등록에 붙여 넣습니다. 세 번째 열에 단어장 이름을 넣을 수 있습니다. 탭으로 구분한 예시입니다.

```text
word	meaning	group
apple	사과	과일
banana	바나나	과일
cat	고양이	동물
ice cream	아이스크림	간식
```

CSV·TSV·텍스트 파일(UTF-8, 1MB 이하)도 불러올 수 있습니다. Excel `.xlsx` 파일을 직접 업로드하는 기능은 아닙니다. Excel 셀을 복사하거나 CSV UTF-8로 저장하세요.

간단한 `apple 사과` 또는 `apple,사과`, `apple|사과`도 지원합니다. 영어 표현이나 뜻 안에 쉼표가 들어가면 탭 붙여넣기 또는 CSV 따옴표를 사용합니다.

```csv
word,meaning,group
pear,"배, 과일",과일
```

**등록 전 미리 보기**에서 새 단어 / 뜻 수정 / 중복 / 오류 행을 확인한 다음 적용합니다. 미리 보기만으로는 저장하지 않습니다. 이미 있는 단어는 기본적으로 건너뛰며 **이미 있는 단어의 뜻도 수정하기**를 선택한 때만 덮어씁니다. 한 파일 안에서 동일한 영어가 반복되면 첫 행을 사용하고 나머지를 중복으로 표시합니다. 오류 행은 제외 개수를 표시한 상태로 정상 행만 등록합니다.

뜻 보기는 동일한 뜻·공유하는 뜻·일부 흔한 동의어를 걸러 네 개를 만듭니다. 임의로 등록한 복잡한 동의어·다의어의 의미까지 완전히 자동 판단하지는 못하므로 등록할 때 대표 뜻을 분명하게 적어 주세요.

## 저장·백업·개인정보

`localStorage['dopa-word-ko-v1']` 한 키에 개인 단어와 학습 기록을 저장합니다. 산수판과 OX판의 키를 읽거나 변경하지 않습니다. 개인 단어를 GitHub에 자동 공개하거나 서버에 업로드하지 않습니다. 계정·로그인·광고·분석 추적 코드는 없습니다.

**중요:** 등록한 개인 단어는 현재 기기와 현재 브라우저에만 남습니다. 다른 기기와 자동 동기화하지 않습니다. 브라우저 데이터 삭제·시크릿 모드 종료 등으로 기록이 사라질 수 있습니다.

설정 → 전체 기록 JSON 내보내기 → 다른 기기의 설정에서 백업 가져오기. JSON에는 단어뿐 아니라 경험치·복습·설정도 포함됩니다. 가져오기 전 현재 기록을 바꾼다는 확인을 받습니다. 개인 단어만 다른 프로그램으로 옮기려면 단어장 관리의 **내 단어 CSV**를 사용합니다. CSV에는 UTF-8 BOM과 수식 실행 방지 처리를 적용합니다.

저장소 사용이 막히거나 용량이 부족하면 경고하고 메모리에서 플레이를 이어갑니다. 이 경우 종료 전에 파일로 백업하세요. 다른 탭이 기록을 바꾼 경우 오래된 기록으로 덮어쓰지 않도록 새로고침을 안내합니다. 브라우저의 선택적 음성 합성은 운영체제나 브라우저의 음성 서비스를 이용할 수 있습니다.

## 개발·검증

의존 라이브러리 없는 ES Modules입니다. 저장소 루트에서 실행합니다.

```sh
python -m http.server 8765
node --test dopa-word/tests/*.test.mjs
pip install playwright==1.55.0
python -m playwright install chromium
python dopa-word/tests/browser.py
```

로컬 주소: `http://127.0.0.1:8765/dopa-word/`. `file://` 더블클릭 실행은 지원하지 않습니다.

전용 CI는 `.github/workflows/dopa-word.yml`입니다. 원작 파일 일치, 기본 단어, 출제·복습·정답·보기 충돌, 단일/일괄 등록, 잘못된 행, 중복, CSV 인코딩, 백업, HTML 입력 안전성을 검사합니다. 실제 브라우저에서 모바일·PC 두 모드, 완주, 입력 방식, 등록·수정·삭제·백업·새 브라우저 복원까지 확인합니다. 병합 후 공개 사이트의 핵심 파일이 커밋과 일치하는지 확인하고 같은 브라우저 검사를 다시 실행합니다. 테스트 결과는 Actions의 실제 실행과 아티팩트가 기준입니다.

구현 참고: MDN [localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage), [SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis).
